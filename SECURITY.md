# Security policy

[简体中文](SECURITY.zh-CN.md)

## Report a vulnerability privately

Please use GitHub's private vulnerability reporting form:

**[Report a vulnerability to CalcKernel](https://github.com/luxine/CalcKernel/security/advisories/new)**

Do not create a public issue or pull request for a suspected vulnerability.
Include the affected CK / CalcKernel version or commit, affected platform and
configuration, impact, and concise reproduction steps. Do not include real
secrets or unrelated personal data. The maintainers will use GitHub's private
advisory workflow to follow up and coordinate a fix and disclosure.

If you cannot access the form, open a [private reporting access request](https://github.com/luxine/CalcKernel/issues/new?template=private_reporting_access.yml)
so maintainers can provide a private route. This request is public: include no
vulnerability description, affected component, exploit code, logs, secrets, or
other technical details.

## Supported versions

Security fixes are developed against the current `main` branch. When a fix is
released, the maintainers will identify affected and fixed releases in the
release notes. Users should upgrade to a release containing the fix.
